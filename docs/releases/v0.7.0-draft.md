Every tool in this release is version 0.7. It adds a fourth tool, the OT Cyber Document Tool, for writing proposals, method statements and other documents in the same SolutionsPT template as the assessment reports.

## Which file to use

| File | What it is | Give it to |
|---|---|---|
| `SolutionsPT.OT.Cyber.Suite.v0.7.exe` | every tool in one portable Windows app (no install), with a home page | people at SolutionsPT |
| `SolutionsPT.OT.Cyber.Suite.v0.7.html` | the same suite as one HTML file; open it in Edge or Chrome | anyone who cannot run an exe |
| `OT.Cyber.Assessment.Tool.v0.7.exe` / `.html` | the assessment tool on its own | consultants and contractors doing assessments |
| `OT.Cyber.Risk.Assessment.Tool.v0.7.exe` / `.html` | the risk assessment tool on its own | consultants and contractors doing risk assessments |
| `OT.Cyber.Report.Review.Tool.v0.7.exe` / `.html` | the report review tool on its own | anyone reviewing a colleague's report |
| `OT.Cyber.Document.Tool.v0.7.exe` / `.html` | the document tool on its own | anyone writing a document in the SolutionsPT template |
| `SHA256SUMS.txt` | checksums to confirm a download is intact | |

GitHub replaces the spaces in file names with dots; rename a file after downloading if you prefer. The exes are not code-signed yet, so Windows SmartScreen shows a warning the first time one is opened (More info, then Run anyway).

## What's new since v0.6

### OT Cyber Document Tool
- A new tool for documents that are not assessment or risk reports but should look like one: proposals, method statements, reports, procedures and short notes.
- A document with a cover prints with the same cover, document control page, header and footer as an assessment report. A short document has no cover and opens with its title.
- Write in an editor with headings, paragraphs, bulleted and numbered lists, tables, pictures, footnotes, links, page breaks and landscape pages. The template decides fonts, sizes and colours, so every document looks the same.
- Red prompts mark what is still to write. The Issue check lists them, and a Final export is refused while any remain.
- Export a Word file as a Draft, with a watermark, or as a Final, which opens read-only.
- Optional numbered headings and a Contents list of linked headings.
- The cover is always one page, and the footer carries the document's own classification.
- A picture taller than a page, such as a phone screenshot, is fitted to the page.
- Pasting from Word carries footnotes, and says what it left out: comments, tracked deletions, pictures it could not read.

### Bringing in a Word document
- Load a `.docx` and it is rebuilt in the SolutionsPT template: headings, lists, tables, footnotes and links become the template's own.
- Pictures are kept. Charts, SmartArt, shapes, text boxes, embedded sheets and equations are carried across as they were and print in the Word export, made smaller only where one would not fit the page.
- A drawing that floated beside the text stays beside the same words, and a diagram drawn as loose shapes and lines is kept whole.
- Anything that could not be carried over, such as comments, headers and footers, hidden text or a hand-made cover, is listed after the import, with a link to where it was. So is anything that was changed, such as list and heading numbers that no longer match a reference in the text.
- The Word file you load is never changed.

### Saving and files
- The document tool saves its own document file, in place where the browser allows, with an autosave copy and a warning before unsaved changes are lost.
- A document file and a Word file both open with Load in the document tool.
- Save as makes a separate document, with its own autosave copy. Two windows of the tool can be open without one disturbing the other's unsaved work.

### SolutionsPT OT Cyber Suite
- The home page has a fourth card and the rail a fourth button, Write, for the document tool, with a tour of a demo proposal.
- A document file dropped anywhere in the suite, or chosen with Open a file, opens in the document tool. A Word file is opened with Load in the document tool itself, and so is a document file over 100 MB.
- The document tool works on its own: no file passes between it and the other tools.

Saved project files from v0.5, v0.5.1 and v0.6 open unchanged.
