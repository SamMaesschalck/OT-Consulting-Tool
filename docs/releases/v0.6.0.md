Every tool in this release is version 0.6. It brings the tools together in the SolutionsPT OT Cyber Suite, adds a tool for peer review of reports, and lets you edit the risk reports section by section.

## Which file to use

| File | What it is | Give it to |
|---|---|---|
| `SolutionsPT.OT.Cyber.Suite.v0.6.exe` | every tool in one portable Windows app (no install), with a home page | people at SolutionsPT |
| `SolutionsPT.OT.Cyber.Suite.v0.6.html` | the same suite as one HTML file; open it in Edge or Chrome | anyone who cannot run an exe |
| `OT.Cyber.Assessment.Tool.v0.6.exe` / `.html` | the assessment tool on its own | consultants and contractors doing assessments |
| `OT.Cyber.Risk.Assessment.Tool.v0.6.exe` / `.html` | the risk assessment tool on its own | consultants and contractors doing risk assessments |
| `OT.Cyber.Report.Review.Tool.v0.6.exe` / `.html` | the report review tool on its own | anyone reviewing a colleague's report |
| `SHA256SUMS.txt` | checksums to confirm a download is intact | |

GitHub replaces the spaces in file names with dots; rename a file after downloading if you prefer. The exes are not code-signed yet, so Windows SmartScreen shows a warning the first time one is opened (More info, then Run anyway).

## What's new since v0.5.1

**SolutionsPT OT Cyber Suite**
- One file opens every tool from a home page with recent files, help, the licence and these notes. Each tool still ships on its own for contractors.
- A file dropped anywhere in the suite opens in the tool that reads it.

**Report review**
- A new tool for peer review. The author sends a review pack from the assessment or risk tool; each reviewer comments on the report as the client will read it and on the engagement behind it, with severity, suggested wording, a checklist, automatic checks and a verdict, and saves a small review file.
- The author imports the review files, replies, resolves or accepts suggested wording in one click where the text can be changed in the tool, and can undo it.
- From round 2, each earlier comment shows where that text is now and what it says now, so fixes can be checked.
- An optional note and needed-by date go with the pack. Approval offers to fill in QA review by.
- A review only warns: the Issue check and the export dialog say when a report is not reviewed or has changed since approval, and nothing stops a Final export.
- Inside the suite, Send for review can open the pack straight in the review tool, and the reviewer's file can be handed back.

**Risk assessment tool**
- A Report page for both reports: rename, hide, reword or reorder sections, as in the assessment tool.
- A QA review by field, printed in document control in both reports.
- An unrated threat prints "Not rated" in the threat register.

**Wording in reports**
- Internal wording ("the tool", "placeholder") removed from client reports, and a double full stop in the risk executive summary fixed.

Saved project files from v0.5 and v0.5.1 open unchanged.
