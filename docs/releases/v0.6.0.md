Every tool in this release is version 0.6. It brings the tools together in the SolutionsPT OT Cyber Suite and adds a tool for peer review of reports. The risk reports can now be edited by section.

## Which file to use

| File | What it is | Give it to |
|---|---|---|
| `SolutionsPT.OT.Cyber.Suite.v0.6.exe` | every tool in one portable Windows app (no install), with a home page | people at SolutionsPT |
| `SolutionsPT.OT.Cyber.Suite.v0.6.html` | the same suite as one HTML file; open it in Edge or Chrome | anyone who cannot run an exe |
| `OT.Cyber.Assessment.Tool.v0.6.exe` / `.html` | the assessment tool on its own | consultants and contractors doing assessments |
| `OT.Cyber.Risk.Assessment.Tool.v0.6.exe` / `.html` | the risk assessment tool on its own | consultants and contractors doing risk assessments |
| `OT.Cyber.Report.Review.Tool.v0.6.exe` / `.html` | the report review tool on its own | anyone reviewing a colleague's report |
| `SHA256SUMS.txt` | checksums to confirm a download is intact | |

GitHub replaces the spaces in file names with dots; rename a file after downloading if you prefer. The exes are not code-signed yet, so Windows SmartScreen shows a warning the first time one is opened (More info, then Run anyway).

## What's new since v0.5.1

### SolutionsPT OT Cyber Suite
- One file opens every tool from a home page with recent files, help, the licence and these notes. Each tool still ships on its own for contractors.
- A rail down the left switches between the tools, keeps each one open with your work in it, and marks a tool with unsaved changes.
- A file dropped anywhere in the suite, or chosen with Open a file on the home page, opens in the tool that reads it.

### Report review
- The new report review tool handles peer review. The author sends a review pack from the assessment or risk tool. Each reviewer reads the report as the client will and comments on it and on the engagement behind it, with a severity and, where useful, suggested wording. The reviewer then works through a checklist and the automatic checks, gives a verdict and saves a small review file.
- The author imports the review files and replies to or resolves each comment. Where the text can be changed in the tool, suggested wording is accepted in one click, and the change can be undone.
- From round 2, each earlier comment shows where that text is now and what it says now, so fixes can be checked.
- An optional note and needed-by date go with the pack. Approval offers to fill in the QA review by field.
- A reviewer can reply on an earlier comment, see what a suggested rewording changes as they type it, and turn a checklist "No" into a comment. The list of sections shows where you are in the report.
- The review tool stays quick on long reports and works from the keyboard. The report is one Tab stop, the arrow keys move through it, and a Keyboard button lists the keys.
- A review never blocks a Final export. The Issue check and the export dialog warn when a report has not been reviewed or has changed since approval.
- Inside the suite, Send for review can open the pack straight in the review tool, and the reviewer's file can be handed back.

### Risk assessment tool
- Both reports have a Report page where you can rename, hide, reword or reorder sections, as in the assessment tool.
- Both reports have a QA review by field, printed in document control.
- An unrated threat prints "Not rated" in the threat register.

### Wording in reports
- Client reports no longer use internal wording such as "the tool" and "placeholder". A double full stop in the risk executive summary is fixed.

Saved project files from v0.5 and v0.5.1 open unchanged.
