First release from the repository. Every tool in this release is version 0.5.1.

## Which file to use

| File | What it is | Give it to |
|---|---|---|
| `OT.Cyber.Assessment.Tool.v0.5.1.exe` | the assessment tool as a portable Windows app (no install) | consultants and contractors doing assessments |
| `OT.Cyber.Assessment.Tool.v0.5.1.html` | the same tool as one HTML file; open it in Edge or Chrome | anyone who cannot run an exe |
| `OT.Cyber.Risk.Assessment.Tool.v0.5.1.exe` | the risk assessment tool as a portable Windows app | consultants and contractors doing risk assessments |
| `OT.Cyber.Risk.Assessment.Tool.v0.5.1.html` | the risk assessment tool as one HTML file | anyone who cannot run an exe |
| `SHA256SUMS.txt` | checksums to confirm a download is intact | |

GitHub replaces the spaces in file names with dots; rename a file after downloading if you prefer. The exes are not code-signed yet, so Windows SmartScreen shows a warning the first time one is opened (More info, then Run anyway).

## What's new since v0.5

**Assessment tool**
- **Issue check** at the top of the report page. It lists everything that would still print in red in the Word report, with a button that takes you to the field where you fill it in, plus warnings worth a look (blank document control fields, unanswered items).
- **Draft or Final Word export.** Draft is marked DRAFT on every page. Final is available once nothing is left to write; it opens read-only and marked as final in Word, and is the file to make the client's PDF from.
- **Executive summary input card** for the instruments that printed the exposure and top-priorities prompts with nowhere to answer them in the tool, and a **Method** field (with a "Use the standard description" button) for the 62443-3-3, posture and supplier reports.
- **Find and jump** now lands on posture questions, and the target is always highlighted.

**Risk assessment tool**
- Now available on its own as a single HTML file and a portable exe, for the first time.
- Shows the suite version (v0.5.1) instead of v0.2.

Saved project files from v0.5 open unchanged.
